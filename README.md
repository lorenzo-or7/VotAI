# VotAI 🇧🇷

Plataforma web para consulta, organização e comparação de candidatos e propostas eleitorais utilizando dados públicos disponibilizados pelo TSE.

## 📌 Sobre o projeto

O VotAI foi desenvolvido com o objetivo de tornar informações eleitorais mais acessíveis e organizadas.

A plataforma permite visualizar candidatos, consultar propostas e comparar informações de forma mais simples, utilizando como fonte os dados públicos disponibilizados pelo Tribunal Superior Eleitoral (TSE).

Este é um projeto pessoal desenvolvido para colocar em prática conhecimentos de desenvolvimento web, banco de dados e organização de informações.

---

## ✨ Funcionalidades

- Consulta de candidatos
- Página individual de cada candidato
- Consulta de propostas eleitorais
- Comparação entre candidatos
- Organização das propostas por temas
- Busca de candidatos
- Filtros de informações
- Páginas de metodologia e transparência
- Compartilhamento de propostas
- Geração de prévias para compartilhamento
- Área administrativa
- Integração com banco de dados

## 🗃️ Fonte dos dados

As informações utilizadas pelo VotAI são provenientes dos dados públicos disponibilizados pelo Tribunal Superior Eleitoral (TSE).

O projeto não possui vínculo oficial com o TSE.
